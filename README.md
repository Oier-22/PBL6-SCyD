# PBL6-SCyD

Karpeta honetan bi karpeta daude, bat egin diren paralelizazio proba denak dauden karpeta eta beste, behin paralelizazio teknika bat aukeratuta rabbitMQ integratua dagoen simulazioa. Simulazio arazorik gabe exekutatzeko "PBL6-SCYD" karpetatik exekutatu behar da, ez da "rabbitMQ" karpeta barrutik, bestela ez ditu behar dituen fitxategiak aurkituko eta.
